# Historical investigation notes

Files under `historical/` are preserved verbatim. Dates, obsolete commit IDs,
workspace paths, earlier conclusions and references to unavailable local
artifacts are historical, not current setup instructions. Some discuss other
parts of the Cordyceps machine and are retained as context for the sound work.

For current conclusions, prefer `docs/evidence.md`, `docs/validation.md` and
`tests/mame/README.md`. In particular, earlier counter estimates, recording
routing assumptions and branch layouts were corrected in later measurements
or during review. Do not use an old handoff's assertion as new hardware evidence.
