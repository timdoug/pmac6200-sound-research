# Original probe artifacts

See the current [probe guide](../docs/probes.md) for build instructions,
preferred result versions and known superseded findings. Prepare the separate
ASCTester dependency as described in the [root README](../README.md).

The files in each probe directory are preserved research artifacts. In
particular, the original per-probe READMEs can contain obsolete commands and
intermediate conclusions; they are not all current instructions. Their exact
bytes are retained for provenance rather than silently correcting old records.
